# CryptoVault

CryptoVault is a responsive cryptocurrency dashboard built with HTML and CSS. It brings portfolio information, market data, and wallet tools together in a clean dark interface.

## Live Demo

[Open CryptoVault](https://yassineladl14.github.io/CryptoVault/)

## Features

- Dashboard with portfolio statistics, BTC/USD and ETH/USD price cards, asset allocation, portfolio health, and risk level
- Markets page with cryptocurrency data and market insights
- Wallet page for balances, deposits, withdrawals, staking, and transaction history
- Settings page with profile, security, notifications, preferences, and connected accounts
- Login and sign-up forms
- Responsive layouts for desktop and smaller screens

## Built With

- HTML5
- CSS3

## Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `dashboard.html` in a browser, or use the Live Server extension.

## Pages

- `dashboard.html` — portfolio overview
- `markets.html` — cryptocurrency market information
- `wallet.html` — wallets, staking, and transactions
- `settings.html` — account settings
- `auth.html` — login and sign-up

Shared styles are in `css/style.css`.
